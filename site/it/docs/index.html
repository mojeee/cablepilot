Guide di CablePilot

Guide brevi e chiare, scritte dall’app stessa: inizia in dieci minuti, capisci la numerazione e sai esattamente cosa c’è nei tuoi file.

Per iniziare

Installa CablePilot su Mac, Windows o Linux, apri un esempio, inserisci simboli, disegna fili e stampa un set di disegni PDF in dieci minuti.
