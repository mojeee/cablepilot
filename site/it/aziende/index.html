Per le aziende

Uffici elettrici, quadristi e integratori possono usare CablePilot senza pagare una licenza e chiederci aiuto dove serve.

Supporto

Aiuto per l’installazione, la migrazione di un primo progetto e l’uso delle funzioni del set di disegni.

Formazione

Sessioni pratiche per il tuo team, sul tuo progetto di esempio.

Funzioni su misura

Librerie di simboli aziendali, cartigli e cornici, macro standard per le vostre schede e migrazione dei dati dai file esistenti.

Perché è sicuro costruirci sopra

Licenza Apache-2.0, formato di progetto aperto e documentato, nessun vincolo con il fornitore: i vostri disegni restano leggibili qualunque cosa accada a noi.

Mettiti in contatto

Apri un argomento nelle Discussioni di GitHub, oppure una issue per un errore o una richiesta di funzione.
